Close the deferred language gaps so the core fish subset is whole:

```
if true; echo a; or echo b; end        ; and/or after blocks
switch $x; case 1; end                 ; case value semantics
echo $argv[1]                          ; list indexing
set -l x a b; echo $x[2]               ; indexed set/echo
```

## Task 1 — indexing: `$var[N]` and slices

Extend src/lexer.rs + src/parser.rs + src/runtime.rs (+ ast.rs if the
Expr shape needs a variant):

- Lexer: after a `$var` part, `[` begins an index spec up to `]` —
  parse as literal int, negative int, or `a..b` range (ints, either side
  optional: `..b`, `a..`, `..`). Nested/bracket contents are NOT
  expressions — reject anything that isn't int/range with a clear error.
- AST: `ExprKind::Index { var, index: IndexSpec }` (or extend the Var
  variant — implementer's choice, document it)
- Runtime: `$x[2]` → second element (1-based, fish), `$x[-1]` → last,
  `$x[1..2]` → first two, out-of-range → empty (fish: no error, zero
  words), index on undefined var → empty
- `set x[2] v` (indexed assignment) is OUT of scope — note in report
- Tests: lexer index tokens, parser Index exprs, runtime 1-based,
  negative, slice, both-open range, out-of-range empty, undefined empty,
  `$argv[1]` in a function, multibyte element (indexing counts chars,
  not bytes)
- cargo test green, clippy clean, commit: `lang: list indexing and slices`
