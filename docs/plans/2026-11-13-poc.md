# fush PoC plan

Design: docs/DESIGN.md (spec authority for this plan).

## Global constraints

- Rust 2024 edition, no unsafe outside Windows API glue, zero C dependencies
- Everything must compile and test on Linux (WSL) — Windows-specific paths
  behind cfg or traits; the PoC binary must run on both
- No explanatory comments in code (greyfish comment policy carries over)
- Builtins: set, echo, cd, exit, test — with fish-like semantics
- Every task ends with `cargo test` green and a DCO-signed commit

## Task 1 — Lexer + parser (fish subset)

Files: src/lexer.rs, src/parser.rs, src/ast.rs
- Tokens: words, $var, quoted strings (single = literal, double = interpolated),
  ( ) command substitution, | pipe, < > redirects, newline/;, # comments,
  keywords: and, or, not, if, else, for, in, while, switch, case, end, set
- AST: Job { commands: Vec<Command> }, Command { args: Vec<Expr> },
  Expr::Literal | Var | CmdSubst(nodes) | Concat(parts)
- Parses: pipelines, and/or/not chains, if/else blocks, for loops, set
- Unit tests: quoting, $var, (cmd subst), nested parens, comments, errors
  with positions (line:col)

## Task 2 — Runtime + builtins + external exec

Files: src/runtime.rs, src/builtins.rs, src/exec.rs
- Env: process-wide + scoped (set -l/-x semantics simplified: global + local scope stack)
- Expands Expr -> Vec<String> (fish-style: $var "one two" splits, literal keeps quotes)
- External commands via std::process::Command (CreateProcess on Windows)
- Builtins: set, echo, cd, exit, test (string/int comparisons, -f -d -x)
- $status after each command; pipelines run all stages
- Unit tests: expansions, pipelines (echo hi | wc), $status, test builtin,
  env scoping

## Task 3 — REPL

Files: src/repl.rs, src/main.rs (wire-up)
- rustyline for line editing + history
- Prompt: "user@host cwd> " (short cwd, ~ for home)
- Multi-line: unclosed block (if/for without end) continues with "...>"
- Ctrl-D exits; Ctrl-C cancels line
- -c "cmd" non-interactive mode (like fish) for scripting/tests

## Task 4 — Windows bring-up + smoke

Files: src/main.rs adjustments, ci/smoke.sh
- cfg(windows) audit: path handling (std::path does the work), no Unix-only APIs
  (fork/exec, signal handling behind cfg)
- Cross-compile check: cargo build --target x86_64-pc-windows-gnu (install target
  if missing) — must produce fush.exe
- Copy to Windows side, run: echo, pipelines, set/cd, external .exe, -c mode
- Write results to ci/smoke results; fix what breaks
