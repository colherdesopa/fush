# fush UX plan: autosuggestions + syntax highlighting

Plan for the first post-PoC milestone (DESIGN.md "After the PoC" step 1).
Base: 2a6dc8f. All tasks keep `cargo test` green, clippy clean, no `//`
comments, DCO commits, rustyline stays the only dependency.

## File structure

- `src/highlight.rs` (new): token stream -> colored line. Pure function
  `pub fn highlight(src: &str) -> Vec<(String, Style)>` plus
  `pub fn plain(src: &str) -> String` used in tests. Style enum local to
  the file. No I/O.
- `src/suggest.rs` (new): history-backed autosuggestion picker. Pure
  functions: `pub fn suggest(history: &[String], buffer: &str) -> Option<String>`
  (longest most-recent match, returns the full line), plus a
  `pub struct Suggester { history: Vec<String> }` with
  `push(line: &str)` and `suggest(&self, buffer: &str) -> Option<String>`.
- `src/repl.rs` (modify): rustyline `Helper` implementation wiring both;
  right-arrow / End accepts the suggestion; Ctrl-F accepts one word.
- `tests/integration.rs` (modify): end-to-end via the non-tty path stays
  untouched; new tests go unit-level in the new modules.

## Task 1 — highlight.rs

- Lex the input with the existing `lexer::lex` (on error, fall back to
  plain, no colors — never block typing).
- Color rules (fish-like): commands that resolve to a builtin -> bold;
  valid externals found on PATH -> bold; invalid -> red. `$var` -> cyan.
  Quoted strings -> yellow. `|`, `;`, `and`, `or`, `not`, block keywords
  (`if/else/for/while/switch/end/case`) -> blue. Options (`-x`, `--long`)
  -> magenta. Comments (`# ...` to end of line) -> gray. Everything else
  default.
- PATH lookup: `std::env::var_os("PATH")` + check `name` or `name.exe`
  exists in one of the dirs (Windows-aware: also PATHEXT-lite `.exe`
  only, keep it simple; on Unix check executable bit).
- Output: `Vec<(String, Style)>` spans; a `render_ansi(&str) -> String`
  helper for the REPL (ANSI codes; rustyline handles the passthrough).
- Tests: builtin bold (`echo`), external bold (`ls` on PATH), invalid
  red (`definitely_not_a_cmd`), var cyan, string yellow, keyword blue,
  comment gray, fallback-plain on lex error, multi-token line mixes
  correctly.

## Task 2 — suggest.rs

- `Suggester::push(line)` appends, dedupes consecutive repeats, caps at
  1000 entries (drop oldest).
- `suggest(buffer)`: if buffer is empty or whitespace -> None. Scan
  history newest-first; first entry that starts with buffer and is longer
  -> Some(rest of that entry after the prefix). Never suggest the buffer
  itself.
- Tests: exact-prefix match, newest-wins on duplicates, empty buffer ->
  None, full match (suggestion equals buffer) -> None, cap behavior,
  dedupe on push, case-sensitive matching (documented: fish is
  case-insensitive on some platforms; we stay case-sensitive for now).

## Task 3 — REPL wiring

- Implement `rustyline::Helper` (`Hinter` + `Highlighter`) on a struct
  holding `Suggester` + the builtin list.
- `Hinter::hint` returns the gray ghost text (ANSI dim) when the cursor
  is at end of line.
- Accept: Right arrow and End already accept rustyline hints natively;
  add Ctrl-F = accept one word (`Editor::bind_sequence` or key event
  handling; if rustyline 19's API makes word-accept awkward, accept the
  full suggestion and note it).
- `Highlighter::highlight` calls `highlight::highlight` and renders
  ANSI. Disable colors when `NO_COLOR` env is set or stdout is not a tty.
- Push accepted/executed lines into `Suggester` alongside rustyline
  history (same content, order).
- History persistence stays as-is (rustyline's file); `Suggester` is
  rebuilt from rustyline history at startup (`history.len()` iterate).
- Tests: unit-level where possible (helper functions); the tty loop is
  verified by a manual smoke recorded in the task report (interactive
  check: type `ec`, see gray `ho` ghost, Right accepts, `ls` renders
  bold, `definitely_not` renders red, `# comment` gray).
- Keep non-tty path untouched.
